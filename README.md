💭 A Few Things I Believe
Technology should solve problems.

Not every problem needs an app.

Not every dataset needs AI.

Not every organisation needs to "go digital."

The interesting part is understanding what the actual problem is first.

Data tells a story.

Numbers by themselves aren't particularly useful.

The interesting question is:

What is the story behind the numbers, and what should we do about it?

Curiosity is a technical skill.

I'm comfortable saying:

"I don't know yet."

Then going down the rabbit hole until I understand it.
